# Differences between the shipped stubs and the runtime that stubtest should
# not report, one regular expression per line, each under the reason it is here.
# Everything NOT listed is the `stubtest` REPORT lane's burn-down, so an entry
# added without a reason above it is a finding hidden rather than answered.
#
# The lane runs without --ignore-unused-allowlist on purpose: an expression that
# stops matching is reported, so this file cannot quietly rot into a list of
# things that no longer exist.

# Every dataclass gains __replace__ at runtime on Python 3.13 and later, which
# is what copy.replace() calls. It is generated by @dataclass rather than
# written, so no stub declares it and every one of the tree's fifty-odd
# dataclasses reads as missing from its stub.
# [source: https://docs.python.org/3/library/copy.html#copy.replace]
.*\.__replace__

# Every class written with PEP 695 type parameters gains __type_params__ at
# runtime, for the same reason: the interpreter supplies it.
# [source: https://peps.python.org/pep-0695/]
.*\.__type_params__

# in the stub, and __all__ differs by exactly that set.
