# The .metta example files this library contributed, one repository-relative
# PATH per line, then the reason it is here. Blank lines and lines starting
# with # are ignored, which is the shape tests/data/example_skips.txt already
# uses for the same kind of list.
#
# conftest.py collects this file and runs each line through `sh run.sh`, so
# every !(test ...) in the file must print its check mark and none may print a
# cross. The engine's full sweep over examples/ stays test.sh's job; these are
# the ones the Python suite runs itself, so a developer who runs only
# `sh extensions/python/test.sh` still runs the MeTTa-language tests this
# library added.
#
# A path listed in tests/data/example_skips.txt is honoured here too, and the
# item reports as skipped with that file's reason rather than disappearing. A
# path that is not in the tree is a collection error, so a moved example says
# so instead of going quiet.
