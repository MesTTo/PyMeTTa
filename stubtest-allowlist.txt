# What `python -m mypy.stubtest metta` may report without the lane failing.
# Every entry is a full-match regular expression over stubtest's own object
# name, and every group below says which fact about this package makes its
# findings not findings. An entry that stops matching is reported as unused,
# so a group that becomes wrong says so.
#
# The lane's subject is the two GENERATED stubs, metta/__init__.pyi and
# metta/_fn.pyi, and whether they still describe the runtime they were
# generated from.

# 1. Every module that ships no stub of its own, which is all of them but the
#    two above. stubtest compares such a module with ITSELF and then reports
#    what source text cannot state about a live object: a NamedTuple is not a
#    tuple subclass, a TypeAlias "is not a type", an overload's implementation
#    takes defaults its overloads do not, a decorator changes a callable's
#    runtime shape, __slots__ reads as a tuple of Literals, 3.13's dataclass
#    __replace__ and PEP 695's __type_params__ exist at run time and not in
#    typeshed's model of them. 109 of the 138 findings on 2026-09-07 were
#    these, and none of them is about a stub.
(?!metta\._fn\b)metta\.[A-Za-z_]+\..*

# 2. The root stub's lazily reached names. `import metta` stays narrow: a
#    satellite arrives through __getattr__ on first access and the stub
#    deliberately declares no member for it, so the runtime exports names the
#    stub does not. metta.__all__ names them and mypy resolves each to Any or
#    to the submodule itself, which is the gap the `verifytypes` REPORT
#    measures rather than something a stub declaration would settle here.
metta\.__all__
metta\.(aio|arrays|bool|casting|catalog|convert|derivation|events|foreign|integrate|lint|manifest|parallel|paths|reflection|remote|set|spaces|strategies|structures|subscribe|tables|testing|vocabularies|wire)

# 3. The root's overloaded doors. Their implementations take `None` defaults
#    that no overload accepts, which is how an optional-argument decorator is
#    written, and stubtest reads the pair as a disagreement. `engine` is
#    @functools.cache, whose wrapper answers (*args, **kwargs) at run time.
metta\.(define|op|engine)

# 4. metta/_fn.pyi's generated namespace class. The runtime object is one
#    _Namespace instance; the stub declares a class listing every safe alias
#    explicitly, because a catch-all __getattr__ would erase typo checking on
#    the closed catalog. The precision is the point of the file, and
#    tests/typing/algebra_surface.py asserts the stub's type at the door.
metta\._fn\.fn
